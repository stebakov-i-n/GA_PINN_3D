# Постановка задачи CFD-расчёта (референс для валидации PINN)

## Зачем

В этом проекте (см. `README.md`) `v` (скорость) и `p` (давление) **не имеют
ground truth**.

В данном документе сформулирована задача CFD-расчёта (например, в
OpenFOAM или аналоге) **с теми же уравнениями, свойствами жидкости и
граничными условиями**, что заложены в PINN, на тех же геометриях, чтобы
получить независимое решение `v(x)`, `p(x)` и использовать его как ground
truth для количественной валидации.

## Уравнения

Стационарные несжимаемые уравнения Навье-Стокса для ньютоновской жидкости,
без объёмных сил и условие несжимаемости:

```
$$\rho[(\mathbf{v}\cdot\nabla)\mathbf{v}]-\mu\nabla^2\mathbf{v}+\nabla p=0,$$
$$\nabla\cdotp\mathbf{v}=0,$$
```

Других членов (нестационарность ∂v/∂t, турбулентность, объёмные силы) в
модели нет — течение стационарное, ламинарное (см. ниже про Re), без гравитации.

## Свойства жидкости

Жёстко заданы в `modules.py:calc_res` (аппроксимация крови как ньютоновской
жидкости):

| Параметр | Значение | Код |
|---|---|---|
| Динамическая вязкость μ | 3×10⁻³ Па·с (3 мПа·с) | `modules.py:19` |
| Плотность ρ | 1050 кг/м³ | `modules.py:20` |

## Геометрия

Источник — `SimVascDataset/<case_id>/<k>_<m>*.stl` (см. `README.md` →
«Структура датасета»). На каждый вариант `<k>_<m>` уже готовы три открытые
поверхности одного замкнутого объёма:

- `<k>_<m>_3.stl` — стенка сосуда;
- `<k>_<m>_1.stl`, `<k>_<m>_2.stl` — плоские сечения на двух концах.


**Единицы**: координаты STL — миллиметры.

**Направление потока**: PINN обучается на каждой геометрии в обе стороны —
основное направление `_2.stl` = вход, `_1.stl` = выход, обратное — вход/выход меняются местами.

**Какие геометрии считать**: В равном количестве из разных выборок (представлены в `full_split.json`) геометрии, отмеченные `accept` в `geometry_selection.json`.

## Граничные условия

- **Стенка** (`_3.stl`): условие прилипания, `v = 0`.

- **Вход** (по умолчанию `_2.stl`): скорость направлена строго по внутренней
  нормали к плоскости входа, профиль — параболический, со средним по сечению модулем
  скорости:

  ```
  V_in_mean = Q / S = 1.5e-6 / 2e-6 = 0.75 м/с
  ```

- **Выход**: условие по давлению, `p = 0`.

## Режим течения

Модель не содержит турбулентных членов — течение ламинарное. Перед расчётом
стоит оценить число Рейнольдса на входе для каждой геометрии:

```
Re = ρ · V_in · D_h / μ,   D_h — гидравлический диаметр входного сечения
```

При референсной площади входа `S = 2e-6 м²` (`D_h ≈ 1.6 мм`) получается
`Re ≈ 420` — ламинарный режим правдоподобен для большинства геометрий, но
конкретные входные сечения в датасете отличаются по размеру, так что имеет
смысл проверить `Re` по факту для каждой геометрии и явно отметить исключения
(если найдутся), а не считать все геометрии ламинарными по умолчанию.


## Что нужно на выходе

1. Полное объёмное решение (`v`, `p`, `x`) в виде тензоров.
2. Задача интерполяции решения на соседние точки не рассматривается т.к. PINN может выдавать решение в любых точках, в частности используемых решателем.
3. Для каждого расчёта указать `Re`, тип сетки/решателя и любые отклонения от постановки выше.
